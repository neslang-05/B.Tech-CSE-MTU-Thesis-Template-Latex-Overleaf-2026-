This appendix provides the comprehensive REST API contract specifications for the core microservices of the AgriVerify platform. The architecture separates the high-throughput Python inference API from the ASP.NET Core business orchestration backend. All API exchanges utilize JSON formatting over secure HTTPS connections.

\section*{1. Model Serving Microservice (FastAPI)}

\subsection*{POST /predict}
Executes real-time visual seed classification and extracts physical DUS parameters from uploaded imagery.

\begin{table}[htbp]
  \centering
  \caption{Specification for \texttt{POST /predict} Endpoint}
  \label{tab:api-predict}
  \renewcommand{\arraystretch}{1.35}
  \begin{tabularx}{\textwidth}{@{} l l X @{}}
    \toprule
    \textbf{Parameter / Attribute} & \textbf{Type / Format} & \textbf{Description \& Contract Constraints} \\
    \midrule
    \textbf{Content-Type} & \texttt{multipart/form-data} & Requires binary file upload stream. \\
    \addlinespace
    \textbf{Payload Attribute} & \texttt{file} (Binary Stream) & JPEG or PNG seed sample imagery ($224 \times 224$ px optimized). \\
    \addlinespace
    \textbf{Success Response (200)} & \texttt{application/json} & Returns classified status, confidence, and DUS geometry. \\
    \addlinespace
    \textbf{Sample JSON Payload} & Object & \texttt{\{"QualityClass": "Healthy", "Confidence": 92.15, "DUSParameters": \{"Length": 9.4, "Width": 2.8, "AspectRatio": 3.36\}\}} \\
    \addlinespace
    \textbf{Error Response (400)} & \texttt{application/json} & \texttt{\{"detail": "Unsupported file format"\}} (Non-image uploads). \\
    \bottomrule
  \end{tabularx}
\end{table}

\section*{2. ASP.NET Core Business Orchestration API}

\subsection*{POST /api/v1/verification/submit}
Accepts multipart uploads from client browsers, forwards imagery to the inference microservice, and logs immutable audit trails to SQL Server.

\begin{table}[htbp]
  \centering
  \caption{Specification for \texttt{POST /api/v1/verification/submit} Endpoint}
  \label{tab:api-verifysubmit}
  \renewcommand{\arraystretch}{1.35}
  \begin{tabularx}{\textwidth}{@{} l l X @{}}
    \toprule
    \textbf{Parameter / Attribute} & \textbf{Type / Format} & \textbf{Description \& Contract Constraints} \\
    \midrule
    \textbf{Authorization} & \texttt{Bearer \{JWT\}} & Required. Valid access token associated with registered farmer account. \\
    \addlinespace
    \textbf{Payload} & \texttt{multipart/form-data} & \texttt{frontImage} (Binary) and \texttt{backImage} (Binary). \\
    \addlinespace
    \textbf{Success Response (201)} & \texttt{application/json} & Returns committed database record ID alongside AI verdict. \\
    \addlinespace
    \textbf{Sample JSON Payload} & Object & \texttt{\{"recordId": "a89d3c-...", "qualityClass": "Healthy", "confidence": 92.15, "isGenuine": true\}} \\
    \bottomrule
  \end{tabularx}
\end{table}
