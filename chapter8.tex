This chapter presents the integration and deployment architecture of the AgriVerify platform. To ensure high scalability, modularity, and robust security, the system decouples frontend presentation from backend business logic and AI inference pipelines.

\section{System Integration Matrix}

The platform operates across four primary integration boundaries, centralized through a secure proxy layer to prevent direct exposure of backend APIs to browser clients. Table~\ref{tab:integration_matrix} summarizes the communication protocols, data formats, and security mechanisms across all subsystems.

\begin{table}[htbp]
\centering
\caption{Architectural Integration Boundaries and Communication Protocols}
\label{tab:integration_matrix}
\small
\begin{tabularx}{\linewidth}{@{} p{2.8cm} p{3.2cm} c X @{}}
\toprule
\textbf{Integration Boundary} & \textbf{Components} & \textbf{Protocol} & \textbf{Key Operations \& Security} \\
\midrule
\textbf{Client $\leftrightarrow$ Proxy} & Browser UI $\rightarrow$ Next.js Proxy & HTTPS, Multipart & Axios interceptors, automatic JWT injection, and refresh token recovery \\
\addlinespace
\textbf{Proxy $\leftrightarrow$ Backend} & Next.js Proxy $\rightarrow$ ASP.NET API & REST (HTTPS) & Centralized request forwarding, payload validation, and internal route abstraction \\
\addlinespace
\textbf{Backend $\leftrightarrow$ ML} & ASP.NET API $\rightarrow$ AI Models & HTTPS / gRPC & Preprocessing (blur/lighting check), OCR metadata extraction, and ResNet classification \\
\addlinespace
\textbf{Cloud Integration} & ASP.NET API $\rightarrow$ Azure AI & Azure SDK & Custom Vision (counterfeit check), OpenAI (insights), and Blob Storage (images) \\
\addlinespace
\textbf{Deployment Pipeline} & Docker $\rightarrow$ ACR $\rightarrow$ Container Apps & Container Engine & Multi-stage Docker builds, secure registry storage, and serverless auto-scaling \\
\bottomrule
\end{tabularx}
\end{table}
